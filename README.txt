## Publish to the existing GitHub Pages website
1. Download and extract this ZIP.
2. Open your GitHub repository: `Sandhiya29gm/SANDHIYA-G-M-PORTFOLIO`.
3. Back up the existing website files.
4. Upload `index.html` and `resume.pdf` (if present) to the repository root.
5. Commit the changes to the branch/folder configured for GitHub Pages.
6. Wait for GitHub Pages to publish, then refresh:
   https://sandhiya29gm.github.io/SANDHIYA-G-M-PORTFOLIO/
